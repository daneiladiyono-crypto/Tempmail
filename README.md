# Daniel.Mail V3

Project temporary email berbasis HTML, CSS, JavaScript dan API Mail.tm.

## Struktur folder

```text
Daniel-Mail-V3/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    └── app.js
```

## Upload dari Android
1. Ekstrak ZIP.
2. Buka repository GitHub.
3. Upload semua isi folder project ini dengan struktur folder yang sama.
4. Pastikan `index.html` berada di root repository (bukan di dalam folder tambahan).
5. Import repository ke Vercel. Pilih Framework Preset `Other`; tidak perlu build command.

## Fitur
- Membuat alamat email sementara Mail.tm.
- Membaca inbox dan refresh otomatis.
- Membuka detail pesan.
- Menyalin alamat email.
- Riwayat alamat di browser.

## Catatan
Tidak ada akun atau tautan TikTok/WhatsApp di website. Password mailbox dibuat acak per inbox. Token sesi disimpan di localStorage browser. Gunakan untuk kebutuhan non-penting saja; jangan gunakan temporary email untuk akun finansial, akun utama, atau pemulihan password. Ketersediaan domain dan API mengikuti Mail.tm.
